Procedural Terrain Mesh Generator

This project implements a procedural terrain system in Unity that dynamically generates mesh chunks and stitches them together seamlessly. The focus is on producing continuous, smooth terrain with correct vertex normals across chunk boundaries.

Running the Project:
1. Clone/download the repo into a Unity project.
2. Open the scene containing GridMesh.
3. Play the scene and move the camera to generate new terrain chunks.
4. Observe seamless normals at chunk boundaries.
